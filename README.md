KubeJS scripts running on the CIR Minecraft server.

Covers recipe overrides and additions for Create and its add-ons, custom item / block / fluid registration, enchantments and loot table tweaks, plus Chinese localization patches for a number of mods.

## Layout

| Directory | Contents |
|---|---|
| `startup_scripts/` | Item, block, fluid and sound registration |
| `server_scripts/` | Recipes, server events, enchantments |
| `client_scripts/` | Tooltips and client-side tweaks |
| `assets/` | Textures, sounds and language overrides |
| `data/` | Enchantments, loot tables and recipe overrides |
| `config/` | KubeJS and ProbeJS settings |
